# 用户手册

面向使用本系统做威胁建模与代码审计的研发/安全工程师。管理员相关操作见
[管理员手册](admin-guide.md)，部署与排障见[运维手册](ops-guide.md)。

---

## 1. 登录与界面

- 访问 `http://<服务器>:8501`，用分配的账号登录；连续输错 5 次会临时锁定 5 分钟。
- 左侧栏：当前用户、界面语言（中/英）、退出登录、使用说明与 FAQ。
- 顶部：页面导航（概览/威胁模型/代码审计/项目工作区/攻击树/数据流图/缓解措施/DREAD/测试用例/报告历史/用户与审计）。
  管理员还会看到「系统状态」与「系统配置」按钮。
- 首次使用：管理员需先在「系统配置 → 模型服务」填写模型 API Key，否则生成会提示缺少 Key。

## 2. 推荐工作流（10 分钟产出第一份威胁模型）

1. **准备描述**（威胁模型页）——任选一种：
   - 直接填写应用描述（类型、认证方式、是否联网、敏感数据）；
   - 上传架构图（PNG/JPG），自动转成数据流图草稿；
   - 从 GitHub 仓库生成草稿；
   - 用「引导式」问答生成结构化描述（推荐，回答 10 个问题即可）。
2. **生成威胁模型** → 得到 STRIDE 分类的威胁清单（场景、潜在影响、缓解建议）。
3. **复核**：若启用「自动对抗式复核」，每条威胁会带 已确认/存疑/已驳回 + 置信度；
   在「项目工作区 → 威胁台账」中逐条确认、指派负责人、备注处置结论。
4. **扩展产物**：数据流图、攻击树、缓解措施、DREAD 风险评估、Gherkin 测试用例。
5. **导出**：报告历史页可导出 Markdown / HTML / JSON / SARIF / Word / PDF / ZIP；
   SARIF 可直接接入 CI 的代码扫描面板。

> 所有生成结果都会自动归入「项目」（默认取描述前 24 字，可在项目工作区改名与维护）。

## 3. 各页面说明

| 页面 | 用途 | 关键操作 |
|---|---|---|
| 概览 | 全局态势 | 项目/报告/威胁计数、风险态势、验证统计、近期活动、用量 |
| 威胁模型 | 核心入口 | 描述准备（填写/图片/仓库/引导式/画图/导入 Threat Dragon）、生成、编辑器 |
| 代码审计 | Agentic 代码分析 | 上传 ZIP 或填 Git 仓库 → 自动扫描（SAST 线索）→ 带证据的威胁入库 |
| 项目工作区 | 台账与治理 | 威胁台账（状态/负责人/备注）、风险看板、定时计划、成员与权限、Webhook 推送 |
| 攻击树 | 攻击路径 | 基于威胁模型生成 Mermaid 攻击树，可下载 |
| 数据流图 | 架构视图 | 生成/编辑 Mermaid DFD，确认后作为其他产物的上下文 |
| 缓解措施 | 处置建议 | 按威胁生成分层缓解措施 |
| DREAD 风险评估 | 量化排序 | 生成五维评分并写回台账风险分 |
| 测试用例 | 验证方案 | 生成 Gherkin 场景（Given/When/Then），供测试同学直接使用 |
| 报告历史 | 检索与导出 | 按项目/类型筛选、查看详情、导出与差异对比 |
| 用户与审计 | 账号与留痕 | 修改自己的密码、退出所有设备；管理员管理用户与查看审计 |

## 4. 代码审计（Agentic）

1. 选择来源：**Git 仓库**（https，支持私有库令牌）或**ZIP 上传**（≤200MB）。
2. 可选：勾选「启用静态分析线索」——先跑 Semgrep/Bandit/detect-secrets 等本机工具，
   产出候选线索再让模型逐条核实（线索可能含误报，报告会标注来源工具与规则 ID）。
3. 运行过程中可查看进度；**任务已持久化**，服务重启会标记为「已中断」，可在 API 重跑。
4. 完成后：新增威胁（带 文件:行 证据）进入台账；报告含「静态分析线索」附录；
   可导出 SARIF 接入 CI。

## 5. 威胁台账的使用要点

- **状态**：待处理 → 已确认 → 已修复 / 已接受 / 已忽略。
- **验证结论**：已确认/存疑/已驳回 + 置信度（由对抗式复核生成，也可人工改）。
- **负责人/备注**：按人跟进；备注里写处置计划与复测结论。
- **筛选**：项目、状态、关键字（场景/类型/负责人）。
- **推送**：配置 Webhook 后可把当前台账推到飞书/企微/钉钉等。

## 6. 报告与集成

- 报告导出：Markdown、HTML（带样式）、JSON（程序处理）、SARIF（CI）、Word、PDF、ZIP。
- **STIX 2.1**：威胁模型/代码审计报告可导出为 STIX bundle（含 CWE 外部引用）。
- **Threat Dragon**：报告可导出为 Threat Dragon v2 模型（继续画图/分派）；
  也可在威胁模型页导入 Threat Dragon JSON 作为分析输入。
- **CWE**：每条威胁自动关联 CWE 编号（SQLi→CWE-89、XSS→CWE-79、硬编码凭据→CWE-798…）。
- **REST API**：见 `docs/api.md`；API Key 在系统配置中创建（可选只读/可写、有效期）。

## 7. 常见问题

- **生成报错缺少 API Key**：到「系统配置 → 模型服务」填写对应厂商 Key；本地模型用 LM Studio 时填端点。
- **模型输出被截断/超时**：换更强的模型或在系统配置调低「最大 token 上限」的分析范围。
- **威胁看起来不准**：LLM 会产生幻觉。请把它当"起点"，用台账复核结论标注处置。
- **中文/英文切换**：左侧栏「界面语言」；切换后立即生效。
- **忘记密码**：联系管理员重置（管理员也可用「强制下线」使旧会话失效）。
- **看不到某个项目**：项目配置成员后，非成员不可见；联系项目负责人把你加入成员。
