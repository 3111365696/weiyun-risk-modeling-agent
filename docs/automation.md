# 定时自动分析与报告/界面定制

## 一、定时自动分析

目标：按计划自动重跑威胁模型，检测威胁变化并推送到 Webhook（飞书/企微/钉钉/通用）。

**配置**：项目工作区 → 项目概览 → 「定时自动分析」卡片
- 检查间隔（小时）
- 威胁变化时推送 Webhook（需先在系统配置中添加 Webhook）
- 保存计划 / 立即执行 / 暂停 / 启用 / 删除

**运行调度器**（独立进程，每 60 秒检查一次到期计划）：

```bash
./scripts/run_scheduler.sh            # 常驻
uv run python -m apps.scheduler.main --once    # 只跑一轮（适合外部 cron）
```

> 也可以用任意调度系统直接调用 REST API 的 `POST /api/v1/full-pipeline`。

**行为**
- 计划到期时：用项目已保存的描述执行一键全流程（六类产物），结果归档到报告历史与威胁台账
- 对比最近两次威胁模型：有新增/消失时，推送摘要（含前 10 条明细）
- 每次执行记录 last_run / last_status（如 `ok（6/6 步，新增 2 / 消失 1）`）
- 项目缺少描述时跳过并记录原因

## 二、报告模板（Word / PDF）

系统配置 → 「报告模板」：
- **报告抬头（品牌）**：默认「威云-风险建模智能体」
- **页脚（保密标识）**：默认「内部资料 · 注意保密」，页脚同时带页码

导出入口：报告详情弹窗（下载 Word / 生成并下载 PDF），或 API `GET /reports/{id}/docx|pdf`。
PDF 通过 Chrome 无头打印生成，服务端需安装 Chrome/Chromium；未安装时接口返回 501 并提示改用 HTML/Word。

## 三、多语言切换

侧边栏顶部「界面语言 / Language」可切换 **简体中文 / English**，选择保存在服务端配置中（重启仍生效）。
覆盖范围：导航、页面标题与说明、按钮/表单标签、设置页、报告历史、项目工作区、用户与审计等 UI 文案；
报告内容语言由模型输出语言决定（可在提示词/应用描述中指定）。
